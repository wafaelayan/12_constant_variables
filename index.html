ثانياً: الثوابت (Constants) في Visual Basic

شرح مفهوم الثابت، صيغة الإعلان والتخصيص باستخدام الكلمة المفتاحية، وتطبيق أنشطة الدرس التفاعلية.

📐

📌 (1) تعريف الثابت (Constant):

«هو مكان داخل الذاكرة تُخزن فيه بيانات لا تتغير طيلة فترة تنفيذ البرنامج.»
المتغير (Variable): تتغير قيمته أثناء تشغيل البرنامج (مثل درجات طالب sgrade، رصيد).
الثابت (Constant): تظل قيمته ثابتة ومحددة ولا يمكن تعديلها برمجياً (مثل Pi، اسم مصمم النظام).
⭐ الكلمة المفتاحية الأساسية للإعلان عن الثوابت
Const

نستبدل كلمة Public أو Dim بكلمة Const عند الإعلان عن أي قيمة ثابتة!

💡 ملاحظة كتاب الوزارة: بما أن قيمة الثابت لا تتغير أثناء التشغيل، يلزم تخصيص القيمة له فور الإعلان عنه في نفس السطر.

⚙️ (2) الإعلان والتخصيص للثابت (قاعدة تعليمة Const):

يتم الإعلان وتخصيص قيمة للثابت باستخدام تعليمة واحدة وفق القاعدة التالية:

Const Name As Type = Value
Const الكلمة المفتاحية للإعلان
Name اسم الثابت
Type نوع البيانات (اختياري)
Value القيمة المخصصة للثابت

أمثلة الكتاب المدرسي على تعليمة Const:

Const LastName As String = "محمد أحمد"

• اسم الثابت: LastName، نوعه: String، وقيمته: "محمد أحمد".

Const Pi = 3.14

• اسم الثابت: Pi وقيمته: 3.14 (تم الإعلان دون تحديد نوع وسيقوم البرنامج بتحديد نوعه تلقائياً).

المفهوم الكلمة المفتاحية / الصيغة الوظيفة ومكان الاستخدام
متغير عام بالمشروع Public sgrade As Integer يُعلن عنه داخل الوحدة النمطية Module وتصل إليه جميع النماذج.
متغير بنطاق النموذج Dim sname As String يُعلن عنه في أعلى النموذج قبل أي إجراء فرعي ويُستخدم بالنموذج فقط.
الثابت (Constant) Const x = 20 قيمة ثابتة لا تتغير طيلة فترة تشغيل البرنامج وتُخصص فور الإعلان.
الحدث التلقائي للزر Click يتم تنفيذه عند ضغط المستخدم بالفأرة على الزر.
الحدث التلقائي للنموذج Load يتم تنفيذه تلقائياً عند فتح وتحميل النموذج في الذاكرة.
